### AOT publish 在本机失败 (环境问题, 非代码)

`dotnet publish -p:PublishAot=true` 报 `输入行太长` + `link: extra operand '?DEF:...'`, 清理 Release 后仍复现。
根因: ILC 10.0.14 的 `Microsoft.NETCore.Native.targets:395` 用
`WriteLinesToFile ... Encoding="utf-8"` 写 `obj/.../native/link.rsp`, 生成 **UTF-8 BOM** (ef bb bf)。
link.exe 把 BOM 当成路径首字符 → 引号配对错位 → 第一个 obj 操作数吞掉后续行, `/DEF:` 成了多余操作数。
对照: 同目录 `SnipasteOcr.ilc.rsp` 无 BOM, 说明这是 link.rsp 独有的写入路径。
与源码无关 (rsp 只有 obj/out/def/lib)。解决: 装 .NET 10 正式 SDK 10.0.404 (ILC 顺带升到 10.0.15) 后重试。
