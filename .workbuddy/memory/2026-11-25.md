## 修复"英译中还是英文"（翻译回显）

根因两条，都在 `TranslateClient`：
1. user 消息是陈述式抬头 `目标语言：简体中文\n\n原文`，模型会当成对原文语言的描述，不去翻译；
2. system 里写着"如果原文已经是目标语言，原样返回"——直接被当成免翻译的许可。

改动：
- `BuildUserMessage`：改成祈使句 `把 <原文> 之间的内容翻译成{目标}，只输出译文。` + `<原文>` 定界；system 去掉后门，改为"只输出目标语言的译文"。
- `LooksLikeEcho(source, result, target)`：目标中文却无汉字（或目标英文却几乎无拉丁字母）判为回显；`TranslateAsync` 先带 `emphasize`（追加"不得原样返回原文"）重发一次，仍回显则 `TranslateResult.Echo = true`。
- 界面：面板标题加「疑似未翻译」、状态栏提示可再点一次；`_barEcho` 让同一块的重试绕过计费去重；`TranslateForm` 状态栏同步标注。
- 测试：离线 607 项（新增祈使句/无后门/强调句/回显判定/截断断言改写），交互 215 项（标题标注、状态提示、可复制、重试不被去重拦截）。
- 未做真实 API 调用验证（无 Key，也不该在测试里联网），结论基于请求体断言 + 回显兜底。

## 译文信息改为"图片下方独立面板"（不再叠在图上）

问题：译文条是 `OnPaint` 的浮层，盖住截图最后几行。用户要求"外侧显示，不要内侧"，并要更大气。

改动：
- `TranslateBarLayout` 重写为面板布局：占满整宽、贴底、`Compute(client, panelHeight, title, copy, body)`；内边距 16/12，标题 12px、正文 13px，上限 200 且不超过视口一半。
- 图片视口 = 客户区 − 工具栏 − `_panelHeight`：`ImageRect` / `ImageViewport` / `ComputeFitScale` / `FitWindowToImage` / `Zoom` 锚点全部扣掉面板。
- `SyncPanelHeight()`：面板出现/变高时窗口向下加高（`_panelGrowth` 记账），底边贴屏先上移窗口，实在放不下才让视口变矮；收起时减回去。`OnClientSizeChanged` 按新宽度重排面板高度（`_syncingPanel` 防递归）。
- 视觉：面板底色用 `UiTheme.Surface` + 顶部 1px 分隔线 + 左侧强调条；「复制译文」增加悬停底色、关闭图标增加悬停强调色。
- 状态栏抬到面板上方（`bottomInset = panelHeight + 8`）；文案改为"译文显示在图片下方"。

测试：`TranslateBarCheck` 重写为面板语义（23 项）；交互自检新增 5 项（面板高度为正、图片不进入面板区、窗口加高而非压图、面板占满宽度、收起后高度还原）。
计数：离线 595 项、交互 211 项（README/AGENTS 已同步）。

验证：离线 595/595；交互多次跑 207~211 通过，失败项均为焦点/剪贴板竞态（基线同样失败，非本次引入，如"真实按键进入编辑控件""覆盖层处于前台"）。


## UI 布局审查（只审查，未改产品代码）

产出 `docs/ui-layout-review-20261125.md` + 截图目录 `docs/ui-layout-review-20261125/`。
方法：临时 harness（`%TEMP%/uishot`，ProjectReference 到 src）真实实例化控件并截屏 + 读尺寸，避免估算。

实测：标注工具栏 632×42（含贴图按钮）/ 600×42；结果窗口 MinimumSize 412×140；源码 88 处 `Color.FromArgb`、`UiTheme` 仅 7 色；字号 6 档（9/10/11/12/13/14）；0 处 `Accessible*`。

核心结论：
- 632/650 = 97%，宽度预算已满，任何"加大按钮/间距"都必须先把颜色+线宽（106px）挪进弹层。
- 建议重排后仍 632：工具 32px/间距 4px、样式按钮 32px、文字按钮 52×28。
- 三处"看得见读不懂"：序号图标像 ⓘ、图钉像台灯、色块下拉三角在命中区外（`AnnotationToolbar.cs:221/352-360/751`）。
- 两套主题（4 浅 5 深）、圆角 6/5/0、白字 on #2196F3 = 3.12:1（不达 AA 4.5）。
- 结果窗口缺识别中/空/错三态；状态栏常驻长句压住图片。
- 参考：Flameshot（右键调色板/滚轮调粗细）、ShareX（选项栏随工具变、22.1 重绘图标）、ksnip（竖排工具+底部设置栏）、Win11 Geometry（8px 浮层/4px 控件）。
