# 2026-11-27

## 修复 AOT publish MSB3030 (无法复制 SnipasteOcr.xml)

- 现象: `scripts/publish.ps1` 的 AOT 发布在 ILC 完成后报 MSB3030
  「无法复制 bin\Release\net10.0-windows\win-x64\SnipasteOcr.xml, 找不到该文件」,
  用户以 -SkipClean 复现, 删 bin+obj 全新构建仍复现 → 不是残留状态问题。
- 定位: SDK 11.0.100-rc.3 的 Microsoft.NET.Publish.targets (L656) 中
  `<ResolvedFileToPublish Include="@(FinalDocFile)">` 把文档 xml 显式列进发布清单
  (受 PublishDocumentationFile 控制, 默认 true), 而 AOT 构建不在 bin 下产出该 xml。
  文档 xml 在本项目只用于构建期 CS1574/CS1587 检查, 不需要进发布产物。
- 顺带发现: 本机 10.0.100-rc.1 SDK 安装不完整 —— SDK 目录缺
  `Microsoft.Extensions.Logging.Abstractions.dll` 等系列, global.json 钉到它时
  任何 dotnet 命令崩 TypeInitializationException → 该 SDK 不可用。
- 修改:
  - `src/SnipasteOcr.csproj`: 新增 `<PublishDocumentationFile>false</PublishDocumentationFile>` (带注释);
  - 新增 `global.json`: 钉 SDK 11.0.100-rc.3 (rollForward latestFeature, allowPrerelease);
  - `AGENTS.md`「构建与验证」补 SDK 环境说明。
- 验证: `publish.ps1 -NoLaunch` 全绿 —— exe 163.3 MB 单文件、两套模型内嵌体积达标、
  产物 `dist\SnipasteOCR-20261127.zip` (110.6 MB)。IL2104/IL3053/IL3000 为 WinForms AOT 一贯警告。
- 待办: 建议安装 .NET 10 GA SDK (winget install Microsoft.DotNet.SDK.10) 后,
  把 global.json 版本改回 10.0.1xx 并复跑发布。

## 防复发加固 (publish.ps1 前置守门)

- 前置检查新增三道闸, 每次发布自动执行:
